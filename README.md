# Homebrew Tap for Grubby

Official Homebrew tap for [Grubby](https://github.com/simonbronner/grubby) — a terminal cockpit for GitHub repositories, pull requests, security alerts, and local workspaces.

## Installation

```bash
# Add the tap and install Grubby:
brew install simonbronner/tap/grubby

# Or tap first:
brew tap simonbronner/tap
brew install grubby
```

## Upgrading

```bash
brew update
brew upgrade grubby
```
